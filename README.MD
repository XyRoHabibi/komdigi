# Aplikasi sewa lapangan padel

## Fitur
- Input Data Pemesan
- Hitung Total Biaya
- Tampilkan data/riwayat penyewaan

## Teknologi
- PHP
- MySQL
- Bootstrap

## Cara menjalankannya
1. Clone repository
2. Pindahkan ke folder htdocs (pastikan XAMPP sudah ada)
3. Jalankan XAMPP
4. Import database
5. Akses di browser : http://localhost/nama_project
